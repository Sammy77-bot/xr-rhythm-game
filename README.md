# XR 音游

这是团队的开发入口。游戏工程、谱面和随游戏运行的素材跟随版本管理。设计稿、原始录音、建模源文件和录屏放在团队共享空间，在[资源索引](docs/resources.md)里登记。

## 从哪里开始

- **开发**：确定引擎和版本后，把工程放在 `game/`，在此补充启动步骤、目标头显和测试方式。
- **音乐与美术**：把关卡用到的谱面、音频、模型和贴图放在引擎规定的目录。大型二进制素材提交前，先和团队确认 Git LFS 的用量和配置。
- **策划与参考**：设计说明放在 `docs/`。Figma、网盘、SDK 文档和参考视频统一登记到[资源索引](docs/resources.md)。

## 怎么协作

1. 在 Issues 写下任务和验收条件，指定负责人。
2. 从 `main` 开分支，例如 `feature/beat-timing` 或 `assets/first-song`。
3. 开 Pull Request，写清改动和测试方法。请一位队友看过再合并。
4. 改同一个场景、模型或工程文件前，在对应 Issue 里和队友约好分工。

管理员可以在仓库 Settings → Collaborators 邀请组员。首次提交第三方歌曲、模型或插件前，在资源索引记录来源和使用许可。
