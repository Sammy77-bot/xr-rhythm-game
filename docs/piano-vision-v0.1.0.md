# Piano Vision v0.1.0

2026-11-12 · XREAL 实琴测试基线

- 视觉模型为 PianoCV 0.5.3 的 KeyNet ONNX。启动脚本从固定上游提交 `7e7dd57b1a2f77d5f4e29a9e244f7911e9022986` 下载权重，并核对 SHA-256 `6AD778F91457CCB71D630FF32C180B43D8D29B4BD9BC1FF9186D762CD95C9C29`。
- XREAL 输入默认使用与本次 Air 2 Ultra 实机匹配的 480×640 左相机 KB4 标定校正鱼眼画面。可在界面关闭校正进行对照。
- 默认核对 61 键规格（36 白键、25 黑键）。键数设置用于核对输出。麦克风单音识别可结合手动填写的最低白键 MIDI 编号点亮对应键。
- 界面记录首次定位耗时、单帧处理耗时和结果更新间隔。

实测确认眼镜相机能持续传输新帧，示例图正常输出 52 白键和 36 黑键。本次保存的实拍失败帧在校正前后均未定位成功，局部自动定位和实琴音高准确率仍待验证。当前框使用相机画面的二维坐标。

双击 `tools/piano-vision/打开琴键识别.cmd` 启动。眼镜输入需另行启动 XR-Gate 相机采集和本机相机桥接，页面通过 `127.0.0.1:8766/frame` 读取灰度帧。
