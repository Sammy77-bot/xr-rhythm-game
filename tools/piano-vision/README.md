# XREAL 琴键识别 Demo

用一张照片、普通摄像头或 Air 2 Ultra 的 XR-Gate 灰度画面，自动找出可见键盘的黑白键，在对应画面上描边。绿线对应白键，橙线对应黑键。这个原型提供键位几何，供后续起始提示、乐谱和数字手共用。

## 电脑上试跑

1. 安装 Node.js 22 或以上，双击 `打开琴键识别.cmd`。首次运行会下载固定版本的模型和依赖，之后可离线使用。页面地址为 `http://127.0.0.1:5275/`。
2. 点「试用示例照片」可验证完整 88 键的识别。换自己的琴时，点「打开琴键照片」或「普通摄像头」。先使用明亮、能同时拍到键盘两端、黑键和白键前沿的画面。桌面确认黑键组、边缘和方向正确后，再换到更倾斜的演奏者视角。
3. 要传给后续应用时，填入实物最低白键的 MIDI 音高并导出。比如完整 88 键琴通常从 A0（21）开始，其他琴型请核对琴本身。留空会只导出相对半音编号。

## 听音与亮键

点击「开启麦克风听音」并授权，单独弹一个音。页面显示音名、八度、MIDI 和估计频率。先定位键盘，再填写画面中拟合键盘的最低白键 MIDI 编号，就可以把听到的音实时映射到相应的黑键或白键。可先打开 Yamaha 示例并填写 21 验证映射。浏览器识别在本机运行，范围为 A1–C7。和弦、连续同音起音、余音与噪声中的准确率需要分别验证。

[双八度听音回放](benchmark/README.md#双八度听音回放) 使用 Basic Pitch 的离线音符事件，按视频时间点亮已标定的琴键。第一人称局部跟踪目前由独立的视频评测脚本处理，网页实时亮键使用网页已有的相机定位。

## 用眼镜取流和显示

1. 在原工作区的 `XREAL-PC-SDK` 目录按 SDK 实作教程启动 XR-Gate 相机采集。在 WSL 启动 `python3 tools/camera_bridge.py --transport shm --stream camera0`，确认 Windows 能访问 `http://127.0.0.1:8766/status` 且 `ready` 为 `true`。Beam Pro 的原生校准路线见 [重构入口](../../docs/piano-architecture.md)。
2. 点「XREAL 灰度相机」，把低音端转到左侧、键盘前沿朝下。依次试静止、缓慢转头、平移、手遮挡以及离开键盘后回看。确认重定位后的键数与键位，并记录延迟和偏差。若广角畸变造成轮廓偏差，下一轮应用与实际采集方向和分辨率对应的 KB4 标定。
3. 在眼镜处于 Windows 扩展屏 2D 模式时，可以把浏览器拖到眼镜显示器，再点「全屏」，直接观察相机合成预览。
4. 镜片内贴合真实钢琴需要单独的 Unity MR 步骤。先用实测键盘尺寸和相机标定求琴面相对相机的位姿，再按帧时间对齐头部位姿，结合相机到头部、头部到左右眼的标定绘制。键盘锚点通过平移和转头检查后，数字手才能按同一坐标演示换指和移手。当前 Demo 已接入取流协议，真实眼镜画面和镜片内对位待实测。

## 键位数据

`piano-keys.json` 保存每个黑白键可见顶面的多边形。坐标为旋转后图像的归一化坐标，左上原点，向右和向下为正。文件带图像宽高和顺时针旋转角度，XR-Gate 帧还带原始传感器时间戳字符串，避免 64 位精度丢失。相机标定要用原始坐标，需先还原旋转。

预览状态栏的「帧处理」包括浏览器收到帧后的转换、识别与绘制。「结果间隔」是连续两次生成键位结果的时间差。真实眼镜还需实测从传感器曝光到镜片显示的延迟。

演奏判定可以用绝对 MIDI 编号匹配琴键。数字手会额外需要琴面三维坐标和每个音对应的指法。若模型拟合到了错误的键数或键盘方向，先在预览中发现并纠正，再采信导出结果。

## 首版验证记录

真实视频对照片段、B 站第一人称候选和定量结果见 [钢琴识别评测集](benchmark/README.md)。

- Windows Edge 中，内置 Yamaha 照片识别出 52 个白键与 36 个黑键，设置最低白键为 21 后导出 MIDI 21–108。
- 用同一张照片生成旋转后的模拟 XR-Gate GRAY8 流，验证画面转正、识别 88 键、保留 64 位时间戳，以及停帧时清除轮廓、恢复后重新识别。
- 部分近景与其他键盘画面未成功拟合。上述结果用于验证识别和数据链路，真实眼镜灰度画面的识别率与轮廓精度待实测。

## 开源资源

- [pianoCV](https://github.com/matheusfillipe/pianoCV) 提供键盘几何拟合与识别运行时，锁定 npm 包 `0.5.3`，Apache-2.0。
- [KeyNet 模型与适用范围](https://huggingface.co/mattf/pianoCV/tree/7e7dd57b1a2f77d5f4e29a9e244f7911e9022986)，Apache-2.0。模型主要用合成图与人工复核画面训练，眼镜灰度广角是本项目的实测重点。
- [ONNX Runtime Web](https://onnxruntime.ai/docs/get-started/with-javascript/web.html) 在浏览器本地推理。
